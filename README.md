# Privacy Policy — Gully King: Downhill Bike Rush

Privacy policy for the mobile game **Gully King: Downhill Bike Rush**, published by
Nexsimp LLP under the Kursor studio brand.

The policy is served as a static page via GitHub Pages:

- **Live URL:** https://ajiteshbd.github.io/privacy-policy/

## Files

- `index.html` — the privacy policy page (GitHub Pages serves this from the repo root).

## Updating

Edit `index.html`, update the "Last updated" date, then commit and push to `main`.
GitHub Pages redeploys automatically within a minute or two.
